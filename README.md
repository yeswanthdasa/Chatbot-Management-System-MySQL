# Chatbot-Management-System-MySQL
Chatbot Management System – MySQL

Project Overview

The Chatbot Management System is a database management project developed using MySQL. It manages chatbot users, administrators, conversations, messages, knowledge base entries, categories, intents, responses, feedback, chatbot settings, and login history.

Objectives

- Design a relational database for chatbot management.
- Maintain user and chatbot conversation details.
- Store predefined questions and responses.
- Manage chatbot categories and intents.
- Retrieve and analyze information using SQL queries.

Database Tables

The project includes the following tables:

1. "users"
2. "admins"
3. "chatbots"
4. "conversations"
5. "messages"
6. "knowledge_base"
7. "categories"
8. "intents"
9. "responses"
10. "feedback"
11. "chatbot_settings"
12. "login_history"

Technologies Used

- Database: MySQL
- Language: SQL
- Tool: MySQL Workbench (or another compatible MySQL client)

SQL Concepts

- CREATE DATABASE and CREATE TABLE
- Primary keys and foreign keys
- Constraints and ALTER TABLE
- INSERT, UPDATE, DELETE, and SELECT
- JOIN operations and subqueries
- Aggregate functions and data retrieval

How to Run

1. Download the SQL script from this repository.
2. Open MySQL Workbench or another MySQL client.
3. Open the SQL script.
4. Review the database name and execute the script.
5. Verify the tables and sample data.

Project Outcome

This project demonstrates practical knowledge of relational database design, SQL queries, table relationships, and chatbot data management.
